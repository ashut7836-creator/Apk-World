# World Mods Official — App versions

## Install the web app (PWA)
Open https://ashut7836-creator.github.io/Apk-World/ in Chrome on Android. When the Install app button appears, tap it and confirm. You can also use Chrome's menu and choose Install app or Add to Home screen.

The PWA caches the app shell so its interface can open offline. Catalogue listings, file downloads, and other live content still need an internet connection.

## Android APK
The Android project is in the android/ folder. GitHub Actions builds an installable debug-signed APK when Android project files are updated or when the workflow is run manually. The workflow publishes the APK to GitHub Releases.

The APK is a lightweight WebView shell for the live website. It opens external links in the device browser and uses Android Download Manager for secure HTTPS file downloads. An internet connection is required for the live catalogue and downloads.

This is a sideloadable test build, not a Play Store release. The CI debug key is generated by the build runner, so if you later install a newly built APK and Android reports a signature mismatch, uninstall the older test build first.
