# APK World

A responsive public website for sharing APK download links, app files and videos, with an owner-only publishing dashboard.

## Publish
1. Configure Supabase by following SETUP.md.
2. In GitHub, open Settings → Pages.
3. Choose Deploy from a branch, branch main, folder /(root), then save.

GitHub Pages hosts the website. Supabase provides the database, owner sign-in and file storage. The upload dashboard will work after Supabase is configured.
